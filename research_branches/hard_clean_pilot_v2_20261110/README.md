# v2：同一硬图目标的稀有三角精确反馈

原v1代码与全部失败记录保留。沿用v1八臂/128更新协议、原始2000步父状态、
K16独立硬样本、CE对照、五成本与MGDA/AdamW。没有删除零反馈目标或扩大抽样。

v1的PubMed首个临时提议中，16张硬图没有出现Species-Species-Species三角，
参考也为0；该分项LOO梯度为0，MGDA因此选择零方向。此现象不能解释为网络
不识别结构或梯度目标已经最优，有限样本没有看到稀有事件即可造成这种情况。

v2对所有“参考缺失但schema可行”的三角子类，直接计算相同硬风险E[T²]：

    E[T²] = E[T]² + sum_tau q_tau(1-q_tau)
            + sum_e p_e(1-p_e) [ (sum_{tau contains e} a_tau,e)²
                                  - sum_{tau contains e} a_tau,e² ]

q_tau为三条边概率乘积；a_tau,e为另外两条边概率乘积。不同三角只有共享边时
才不独立，最后一项包含两倍无序共享边协方差。该等式依赖当前条件独立边抽样，
不是完整反向生成图的三角期望。参考缺失组三角目标为各类E[T²]平均。
用CPU autograd对p求导再乘p(1-p)，作为对应margin的精确导数。真实图上不枚举
所有图、不逐边编辑，仍为一步网络前向。其余四组保留原LOO估计。

有限图CPU枚举验证值/导数误差5.55e-17；包含方差和共享边项，不能称为旧软均值损失。
MGDA非线性和AdamW的局部保证限制仍在，任何其他零反馈组仍按冻结停止规则处理。
