# R25：检查小势函数是否真正完成优化

R24仍须全部验收；当前半闭合IMDB终点相对Q出现优化顺序差异，不能挑最好fit。P只有16/52个系数，候选特征固定，交叉熵对这些系数是凸函数；继续把它当大型网络做固定800次小批更新，可能留下优化误差。先只读计算全部R20 P的完整加权训练CE、参数L2和投影梯度残差，判断是否存在可测优化缺口，不用生成误差挑优化器/训练样本。

唯一新候选F：沿R19/R20同一数据/标签/归一化/势差表示/二次非负约束，直接优化期望回放的完整目标：.25*旧全部记录平均CE + .25*旧noop标签记录平均CE + .5*新1280记录平均CE + .5*1e-4*||w||²。旧random与排除已选old的noop均具有相应均匀边际，故前三项对应原回放权重；最后一项把此前AdamW的decoupled weight decay改成显式标准参数正则，必须披露这项优化/正则实现变化，不称完全等价。没有参考结构误差损失、奖励或推理oracle。

两个参考各零初始化一次确定性SciPy L-BFGS-B，线性系数无界、二次下界0，maxiter400/maxfun800、ftol1e-12/gtol1e-7。用float64固定特征优化并float64部署这一小模型；原输入整数计数与delta编码不改，第一阶段原MLP仍float32。每参考一个确定性系数fit，重复执行用于工程复现，不计新增训练seed；不得用相同确定性重复制造SD。若投影梯度max>1e-5或目标不低于所有旧P（1e-8容差），不能进入部署；保留未收敛状态，不另加迭代挑最佳中间点。

工程：NumPy与Torch double损失/梯度<=1e-9，8坐标中心差分误差<=1e-7，求解器重复结果/目标数值<=1e-10；先20次目标梯度评估按2倍1600次<=600秒成本门。最多2科学优化fit（每fit<=800函数评估）、完整独立求解复现；函数/梯度调用与优化迭代分别计，不换算成原SGD更新。所有旧P目标与残差保留。完成后只有两参考都满足数值/KKT门才单独冻结生成比较；本票自身0新图。

这检验有限优化误差，不承诺结构收益。即使目标求解充分，也不证明目标与生成指标一致、更优图分布、精确逆扩散、隐私或效率优势。后续仍保留S/U/P/Q/N/NS、固定候选/零步及完整流程对照；确定性训练的生成SD和训练数据扰动不确定性不能混为一谈。
