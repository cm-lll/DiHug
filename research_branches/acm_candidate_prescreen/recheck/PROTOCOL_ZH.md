# ACM 连通正式轨迹候选预筛复核

使用两个已验收的 ACM 后缀档案 `acm_solver_repair/deploy` 和 `additional_confirmation_v1/deploy/acm`。纳入档案中全部保存了完整 trace、候选计数增量和终图的正式请求，共 24 条 2,048 步路径，七张连通起点图。主要判断使用 C 起点，D 起点单列。任何不存在的后缀不重跑。轨迹只跟随原来落盘的有效动作；两个预筛器的选择永远不推进状态。核查档案端点哈希、训练与复核的图状态指纹及编辑不变量。

沿用前次组合目标，等权平均分类型三角与跨关系四环的归一化 L1 误差降幅。仅比较相同便宜特征的学习预筛与残差分槽，精算 2 或 4 个候选。使用前次的两套浅层树拟合各自评分，先原数据确定性复原并核验前次留出所选槽位。没有用连通复核档案调参或训练。两种方法在同一状态上使用同一批已存候选和便宜特征，只去除显式不操作和重复动作。挑选后才读取真实结构增量及检查能否保持整图连通。碰到不连通候选占用一个名额。不操作作免费的零收益回退。

每条轨迹汇总后，各路径在同一起点内等权，两个已拟合预筛器等权。按起点报告平均最佳正收益、正收益命中率、差值、逐状态配对及两个复原模型分别的结果。准备进行生成验证的证据门为同一预算下，学习在三个 C 起点的平均收益都严格领先且两套复原模型的跨 C 起点均值均领先。D 起点作为额外适用性信息，不用来代替 C 判据。无新候选采样、无新生成、无改稿。最多六个 CPU worker，单次硬停五分钟。
