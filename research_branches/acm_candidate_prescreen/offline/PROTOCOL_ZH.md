# ACM 便宜特征预筛的离线验证

仅使用有来源验收的 ACM 既有 pilot、bank4 扰动档案。两个档案各 19 条完整轨迹、1,664 个状态。从一个档案拟合，在另一个档案整轨迹测试，两个方向分别报告，再对 38 条测试轨迹等权汇总。另报告出发状态已经连通的子集。校验轨迹与图状态指纹无交叠。剔除训练数据中人为注入的逆编辑及其重复项，并按实际替换内容去重。不编辑作为精算完成后免费的零收益回退。

目标固定为三角分类型相对 L1 与跨关系四环相对 L1 的平均误差降幅。用已独立审计的状态计数、候选真实增量和连接分量掩码生成训练标签。预筛时隐藏真实增量与连接分量掩码，最终精算时若入选候选不能维持原连通分量数则计入预算且不能执行。预筛特征为操作关系、端点分类型度、最多四个现有邻居抽样形成的闭合近似和当前的计数残差。各方法使用相同可见候选和随机破平。用一个固定的小树模型拟合真实单步误差降幅，无模型或参数筛选。

所有方法每批最多精算 K=1、2、4、8，主读数 K=4。比较均匀随机（精确期望）、关系类型轮转、当前结构残差加权分槽、按抽样闭合增量直接排序，以及用相同便宜信息的学习预筛。类型和残差分槽各关系内部也使用抽样闭合近似排序。报告最佳正收益、获得正收益的概率、距全候选直接择优的差距、轨迹等权配对胜负以及连通子集。候选只来自保存的短名单，不能检验学会生成名单外的编辑、端到端墙钟时间或最终生成质量。

工程检查为档案与来源哈希、原轨迹可重建至归档端点、标签和候选槽位对齐以及候选预算公平。无新图、无新候选、无论文改动。两次 CPU 拟合，运行硬停 180 秒。
