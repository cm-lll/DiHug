# 保留边不确定性的关系度分布辅助：独立审查候选

当前状态：CPU实现和资产准备通过；没有正式训练入口或启动器，没有GPU验收、训练或生成效果。正式授权字段为false，不修改任何已有A/输入增强/输出增强实验。

## 目的与唯一公式

基底为当前192节点单参考A晚CN，普通单输入IID时间、CE、AdamW、EMA0.99、R1/T1000不变。不加入额外三角/分量输入，不改CN，不加三角/连通约束，不修改反向采样。

模型原有的干净边概率p_ij来自同次去噪输出。给定p，关系r下节点i的独立伯努利关系度多项式为G_i,r(z)=product_j[(1-p_ij)+p_ij*z]。其系数h_i,r(k)表示该代理下Pr(D_i,r=k)。按关系r与端点类型a构成组g，F_g(k)=mean_i sum_{d<=k}h_i,r(d)。参考CDF由本次训练图X0的同类型关系度直方图得到，不要求生成节点按ID对应参考节点。

冻结诊断公式作为本候选：

L_PB = (1/|G|) sum_g [1/(2 M_g) sum_{k=0}^{M_g-1}(F_g(k)-F_ref,g(k))²]

L = sumCE/S + λ L_PB，**建议λ=1.0**，两数据集同值；S=18336，原CE系数完整保留，无normal2的1/2，没有每步按aux自身除权重。每次输入加入一次，使用同次p0，不新增去噪网络前向。每组M_g由声明库存和实际可动关系候选邻居数确定，不按结果调系数。

组均权、整数度阈值均权、容量归一化和λ=1均是明确的设计选择，不是理论最优权重。总度仅用于评价，不再叠加一项总度损失。固定零/固定一关系与参考一致，不计入可动组均值；空组不参与。无任何可动组时返回可求导的零。禁止单块概率和冒充完整分布，当前只接受R1完整合法槽覆盖。

`pb_degree.py`中`RelationDegreeCDF`冻结目标及schema绑定，`_GroupedCDF`实现批量多项式递推及解析反向，`combine_normal1`提供损失组合接口。**此接口尚未接入正式worker**，调用方仍须负责支持CE、原输入抽样、模型/AdamW/EMA/RNG事务及入口鉴权。不得复制旧输出增强worker而把它的输入增强模型当成原A。

## 边梯度与边界

d Pr(D_i,r<=k)/d p_ij = -Pr(D_i,r without ij=k)。无向变量梯度汇总两端，不将无向边重复计数为两条。计算包含整个PMF，不用均值/方差正态近似，不剪尾，不Monte Carlo抽样，不取整期望度，不做逐边试删。0/1概率保持数学边界，模型原p0链式导数保留。实现支持一阶反向，不支持高阶导数。

目标值界为[0,0.5]，完美硬参考预测时为零；这不保证训练单步损失下降、优化器稳定或生成结构改善。匹配的是**独立边代理下期望直方图的CDF**，不是完整反向链的图分布，也不是期望图间距离。节点间共享边不影响直方图期望的线性计算，但图间波动、联合关系度、三角和连通性仍未约束。
