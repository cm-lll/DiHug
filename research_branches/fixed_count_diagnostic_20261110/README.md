# 固定关系边数的连接安排诊断

目的：在同一批保存概率上，将“数量变化”与“同数量下的邻居安排”分开观察。只读取已有输入、图与概率，不构建去噪网络，不读取完整模型到GPU，不训练或运行扩散生成链。当前用户批准的诊断，不替代正式任务定义。

对各关系r，给定保存的独立边概率p和参考关系边数m，抽取

P(b | sum b = m) = 1[sum b=m] product_i p_i^b_i (1-p_i)^(1-b_i) / P(sum B=m).

内部概率0/1严格保留。若条件事件概率为0，报告不可用，不裁剪到epsilon。先移除确定槽，以log odds构造基本对称多项式前缀DP；从尾部依条件概率顺序抽样。k较大时对缺边作补集，以降低内存。不是Gumbel top-k、按概率顺序无放回或确定性选最大值。

DP时间O(M min(m,M-m))，空间相同；完成DP后K份样本用同一表顺序采样。对同一关系所有log odds加同一常量，条件分布不变。这是诊断能去除关系共同密度偏移的数学依据，但并不意味着真实更新只包含这种偏移。

测试覆盖六槽全部64种输出、26个非零条件事件，逐路径概率和独立枚举核对；包含0/1支持、补集、共同log-odds平移不变性。真实图逐份检查各关系计数。

固定面板：四旧模型×六噪声时间×三个预测器状态×32份条件抽样=2304；原独立抽样2304复用；另IMDB/PubMed各32份同计数均匀随机图作参照。保留所有时间/seed，不选最好样本。旧状态为先前已观察病例，不是独立确认。共享均匀数使条件抽样前后配对；原独立抽样与条件抽样来自不同抽样律，不声称一一对应的改图。

评价：复用原HardScore定义，报告匿名联合关系度、类型三角有/无风险、分量成本，另保留总三角绝对误差、LCC、孤立点、低度/hub、按类型关系度W1和所有类型三角计数。条件化会同时改变边依赖、波动和均值；诊断结果不能解释为纯参数因果分解，不能证明正式采样固定数量即可修复。

资源：一个CPU计算线程，独立看门狗实际RSS2GiB、600秒，worker540秒保存中断。GPU0。原资产SHA在protocol.json绑定，退出时重验。脚本不安装依赖，不覆盖历史结果。输出目录已存在时拒绝重跑。
