# 对固定9c721ec审查意见的处理

结论：接受审查的工程与研究边界。确认旧查询输出测试会被零投影掩盖，**不等于确认同分量实现错误**。本次仅修改隔离分支代码、补CPU合成测试与说明；无GPU、正式训练或模型生成。

1. **非零投影测试已补。** 构造两个非平凡分量和孤立点，6个查询的人工预期标志为[1,0,1,0,1,0]；投影列设为[1,…,64]，检查完整数值、重排、三个块、查询扩充及RNG不变。不是比较两个恒零输出。原缓存污染/关闭拒绝测试保留。
2. **迁移工厂加强。** 拷贝之前核对类型数、关系数、逐项有序schema与精确关系先验。新增同形状schema顺序颠倒和先验改变的拒绝测试。模型对象不保存节点实体及类型命名的全部历史语义，因此文件哈希、数据身份、类型名到索引映射、初态确为0步和配置仍必须由正式调用方绑定，不能称工厂已证明所有资产身份。
3. **重复计数已优化。** 每分量只建立一次类型直方图，随后查表分发。只消除这部分的二次重复扫描，不声称整个提取器线性。与9c721ec原参考实现对全部1024个五节点图的完整返回值逐值一致；无需改特征定义。未以此宣称192节点GPU预算已通过。
4. **论文边界修正。** 分母是声明schema库存上界，未按固定零支持收紧，非实际可达容量/闭合率。高噪声不必然变稠密或全连通。DiGress已包含循环及连通性相关谱特征；这里只研究对typed-CN异质基线的表示增量，不宣称首次加入这些信息。
5. **证据归属。** 用户提供的独立2000随机图检查是外部审查证据；本机未取得其脚本/明细，不能列作本次重跑结果。原18项恢复回归是已发布旧回执，本次不重复。当前候选套件扩为11项，全部通过，CPU单线程、CUDA未初始化，详情见CPU_TESTS.json。
