# E-earlyCN数量辅助损失修订：唯一候选审查包

仅准备，不是训练授权。来源1665ff3acc2fa3d76e116e498cbd2b9475453927；原公式、旧准备与失败记录原样保留。本包在独立目录实现损失、CPU检查和500步阶段计划，没有模型加载/前后向、optimizer.step、GPU访问、完整生成或正式审批。旧9000/13小时方案不继续。

## 一、完整公式与选择依据

对关系r，J_r为全部唯一无向可动槽，K_r=|J_r|。原网络有边p0为p_i；固定支持中必有边数为b_r；训练X0的完整关系边数为m_r：

    mu_r = b_r + sum_{i in J_r} p_i
    delta_r = mu_r-m_r
    s_r = sqrt(max(m_r,1))
    u_r = delta_r/s_r
    rho(u_r) = sqrt(1+u_r^2)-1
    L_count = mean_{r:K_r>0} rho(u_r)
    lambda = 0.001  （两个数据集、所有关系共用）
    L_input = sumCE/18336 + lambda*L_count
    L_normal2 = (L_input_1+L_input_2)/2

一次清梯度，两份输入分别反向并释放独立计算图，最后一次AdamW、一次EMA0.99。p0仍来自原FP32网络/支持投影，辅助求和与函数用FP64；没有q、度真值或目标数量输入网络。推理不变。

平方根数量尺度是预先固定的启发规则：比除以m保留更多常见关系的中等残差信号；取消K分母，不再随候选槽数直接稀释数量梯度。它不是“边独立”“泊松方差”“标准误”或置信阈值的声明。相同lambda与关系均值仍不保证各关系/数据集梯度相等，IMDB可动关系R=5、PubMed R=10。

|delta|=s处达到渐近斜率的1/sqrt(2)，是平滑转折位置，没有硬截点。AA/SS目标3时s=1.732；GD目标137时s=11.705；DC目标267时s=16.340。小残差近似delta^2/(2*max(m,1))，大残差近似|delta|/s-1。

lambda一次选为0.001，未试多个值：去掉K后不盲用原0.01，而以数量导数上限检查极大稀有误差的量级。在AA m=3,R=5时，加权数量导数上限0.00011547；p=0.5时辅助有边logit梯度上限2.887e-5，和无边CE的2.727e-5同量级。GD m=137,R=10时上限8.544e-6，不随初始化几千条误差继续放大。这是选择依据和尺度锚点，不是必须等于CE的门槛，也不是优化器安全证明。lambda及公式在扫描本轮结果前宣布固定，检查后未调整。

目标0时s=1，合法槽仍可动，不把零训练频数变成schema禁止。无可动槽关系从平均分母排除，但先检查目标必须等于固定支持；全无可动槽返回可微0。固定有边贡献只加一次、无梯度。候选概率须有限且在[0,1]，支持目标需可实现；不剪裁残差或概率，不隐藏异常。稳定实现rho=(u/(hypot(1,u)+1))*u，避免近零相减消失。

## 二、梯度含义

对一个可动槽的有边logit，z=l_present-l_absent，p=sigmoid(z)：

    d(lambda*L_count)/d mu_r = lambda/(R*s_r) * u_r/sqrt(1+u_r^2)
    g_aux,i = 上式 * p_i*(1-p_i)
    g_CE,i = (p_i-y_i)/18336

对无边logit符号相反；normal2两者都乘1/2。数量导数绝对值不超过lambda/(R*s_r)，这不限制完整网络参数梯度、梯度范数或Adam更新。它仍含p(1-p)，不能解决错误饱和概率自身难以通过此项改变的问题。数量对了但hub/联合度/闭合错了时，此项仍可为零。

已有汇总可推出的单槽梯度比例上界为：

    c_r = lambda*18336/(R*s_r) * |u_r|/sqrt(1+u_r^2)
    y=0: |g_aux/g_CE| = c_r*(1-p)
    y=1: |g_aux/g_CE| = c_r*p

因此下表是上界，不是实测正负槽/参数梯度。共享参数的梯度汇合、抵消和优化器作用未知。相对初态或旧模型的反事实计算，也不意味着新目标训练后会产生同一输出。
