# 指标来源、可比口径与缺项

本票基于a4a87a19ca17ba866300ea8bcbe7b49e27302a9e的64张PubMed O生成图。原始图和评价未改写；新派生图明确为全关系无向图最大连通分量的后处理版本。节点类型仍为Gene／Disease／Chemical／Species，关系编号与schema不变。

## 后续异质结构评价

- **incident4 W1主口径**：每类型在4个关联关系上的整数度经验PMF分别计算未缩放一阶Wasserstein，再对4关系取均值。类型权重冻结为参考40/192、74/192、66/192、12/192。原192节点版本与已封存值逐图复核；LCC版本的PMF分母是实际该类型保留节点数。固定参考权重用于避免删除某类型节点后改变其评价权重。
- **all10兼容值**：同一固定参考类型权重，平均全部10列；非关联列均为零，必须为主W1的0.4倍。不是旧E07数值的直接替换。
- **实际类型权重兼容值**：另列incident4_actual_typeweights，采用保留图各类型占比。两种权重值不混名；不按结果选择主口径。
- **完整联合关系度TV**：每类型完整10维整数度向量频数归一后TV，再用固定参考类型权重汇总。各维向量未拆开重拼。类型缺失时该条件分布及主汇总null，不能补成零度节点或跳过类型。类型数量／比例偏差单独报告。
- **度及尾部**：总度、各类型总度、每关系度的完整直方图；最大／次大、P90/P99、排序谱、零度／度≤1数量、标准Gini、固定top5度质量占比。高尾部阈值采用参考各类型ceil(P99)，至少1；所有图用同一个阈值，不由当前LCC重新选。
- **类型三角**：4类型允许的20种带重复类型三元组全部列出，实际边关系由唯一类型对schema确定。数量／参考绝对误差／归一化组成及TV分列；参考为0仍列生成数量，不硬禁该类别。
- **闭合补充**：原冻结PubMed评价没有IMDB专属DMA闭合字段。本票明确新增“已有二跳/三角计数的描述性分解”，覆盖40种(端点类型a,中心类型b,端点类型c)，端点a≤c。分母为当前真实边构成的无序二跳实例；分子为端点已有边的实例。另对端点对去重，分母/分子分别计“至少有该中心类型路径”的唯一节点对。分母0保持null及原因。所有40类的路径分母加总=wedge，分子加总=3×三角。此描述性适配不是新训练指标，也不是已有PubMed字段的伪复现。
- **MP1/MP2/MP3**：严格复用冻结paths函数，长度就是1/2/3条边。节点互异、反向规范化、每条无向简单路径计1。逐模式数量、组成TV、总量、每节点量全部保留。
- **旧投稿typed walk**：另用已有walks函数统计允许回退和重复节点的有向walk实例；将正反模式归在同一键但不把实例数除2。与上项简单路径不可混用。
- **样本差异**：同seed/同读出两图的原编号对齐边Jaccard、对称差及节点Jaccard；同时给不依赖编号的两样本度W1、类型三角和MP2组成TV。节点数/边数不同可证明非同构；大小相同不额外跑昂贵同构搜索，记未判定。以上均不证明总体多样性充分。

## 比较、分母与未定义值

所有图按实际保留节点构建，关系容量n_a*n_b或n_a(n_a−1)/2，density=edges/capacity，容量0为null。节点或关系保留比原分母0时null。参考确为192节点、926边的全连通图，其LCC就是自身。

数值原值、参考、逐图绝对误差、分布距离四组分列。每个训练seed先平均两图，再分旧2／新6／全8；配对方向固定EMA−raw，处理方向固定LCC−original。负的误差差代表更接近参考，原数量差不直接解释为改善。聚合遇到任一必需未定义项时为null，同时记录有效/预期数量和原因，不能删字段或只平均成功项。

类型、边、三角、机会、路径及规模随LCC处理机械变化；W1/TV变化也可能来自去掉低度节点。主体LCC占比1和无孤立点是选择规则后果，不计作网络新能力。无新模型前向、训练、采样、概率改变或补边。

模式组成TV保留原函数的边界约定：两边都无该类模式时为0，仅一边无模式时为1。本批真实图的总三角和MP总量非零。这个历史TV约定与闭合率的零机会分母不同；后者始终null，不填0。
