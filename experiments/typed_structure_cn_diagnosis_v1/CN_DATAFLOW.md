# 当前CN实际数据流（只读源码核对）

来源为本票绑定的 `package/hsgd/common_neighbor.py`、`model.py`、`computational.py`、`vendor/sample_edges_utils_typed.py` 及 `model_variants.py`。逐文件SHA见audit.json；这些科学文件没有修改。下面维数是实际width256、4类型、10关系、edge64、global128、joint128配置，不是泛指模型。

## 1. 一条候选边对应哪份CN

完整冻结Xt的物理边先镜像为双向索引；Wedges按中心w枚举无序邻居对u<v，键为u×N+v，并保存w及两条真实边的关系编号。只统计Xt已有边，不把临时查询边当成存在；恰好被查询的真实边仍保留。

查询的规范端点键通过searchsorted找出全部匹配楔形。qid始终是输入查询行编号；每条共同邻居路径通过index_add累积回qid，不把不同候选对合成图级CN。路径65536分段只控制内存，不截断。两个200万资源门保留。

计算图可能排序/合并边，但get_computational_graph再次用候选端点键找query_index并检查键相等；联合头的edge、左右端点、关系、当前状态、旧logits和CN都按这份query_index/查询顺序排列。诊断输出再按完整槽ID写回。本票8输出的ids/query/family/state映射通过，四输入73344槽的类型CN与独立邻居集合交完全一致。该CPU检查不冒充重新跑过旧端点交换/重编号网络验收；旧验收直接复用。

## 2. 两种CN信息如何变换

|信息|实际变换|进入联合头的维数/尺度|
|---|---|---|
|每类型共同邻居个数n_k|FP32计数→log1p(n_k)|4维、非负；不是原整数，也没有除以类型容量|
|是否至少一个共同邻居|1[Σn_k>0]|1维、0或1|
|共同邻居学习表示|每个w的281维输入→Linear(281,32)→SiLU→Linear(32,32)→SiLU；随后按同一候选对所有w取平均|32维连续向量，可含负值；不是概率，没有softmax或单位范数归一化|

281维输入=共同邻居h_w(256)+类型one-hot(4)+两段关系one-hot之和(10)+目标候选关系one-hot(10)+t/T(1)。两段关系之和是无序多重集，值0/1/2，保留关系类别而不保留端点方向。该schema一类型对对应一个关系族；不能据此宣称适用任意多关系同类型对schema。

h_w来自**共享主干第一层Transformer在完整Xt真实边上的输出**，不是独立新编码器，也不是整张查询计算图的最终节点表示。其输入已加当前度分支；D/E再加ReFeX投影，E再加RolX投影。因此E的CN内容随ReFeX/RolX及共同训练而变化，不是把A训练好的CN原封接入。零真实边时按实现返回输入隐藏表示；无任何共同邻居的候选对整段37维返回零。

已有连续编码包括：计数的log1p连续变换、关系/类型条件下的可学习phi MLP、共同邻居上下文Transformer、最终联合MLP。**“把整数CN嵌入”并非尚未实现的新机制。** 原始4维计数并没有独立embedding查表，但已被联合头学习线性混合并非原样决定概率。

## 3. 联合头位置及缓存

联合输入按顺序为edge64、端点均值256、端点绝对差256、全局128、时间1、Xt统计20、关系10、当前边状态2、原主干logits2、CN37，共776维。CN32位于[739,771)，计数4位于[771,775)，存在位于[775,776)。再经Linear(776,128)→SiLU→Linear(128,2)，softmax给p0、原支持覆盖和原Bayes核给q。C关闭全部CN路径及37列，输入739维。没有CN分数直接加到输出概率的捷径。

每份Xt独立FrozenTypedContext，状态token、时间、参数版本及缓存张量版本有检查；context.close清掉CN节点/楔形。固定ReFeX/RolX数组可在一个Xt上下文复用，学习投影在joint_predict计算，不跨优化器更新缓存。科学源文件未见本票可确认的候选错位或查询边污染错误。

## 4. 实际尺度与缺项

从已保存Xt仅CPU计数得到 `cn_count_scales.csv`。普通t1四类型log1p最大值为2.7726/2.4849/3.2189/1.3863；普通t500为1.6094/1.6094/2.4849/1.0986；C-X499为2.0794/2.0794/2.3979/1.0986；E-X499为1.7918/1.7918/2.0794/1.0986。各列均值/RMS完整保留。数字是数学log1p的CPU FP64统计，GPU接口会转FP32，不伪称已捕获逐位GPU特征。

32维phi均值、其他头输入、各块乘头权重后的实际RMS/峰值**未保存**。追加指示到达时8次前向已结束；因此不补跑，不声称CN数值支配头，也不从最终logit反推内部贡献。两种模型的参数不同，E−C最终logit差并不能单独归给37维CN。

本票据此不建议再加编码MLP或先改归一化。训练时CN特征随机丢弃只是一个待检验的依赖稳健性假设；与“整数未编码”无关。本文件没有新增模型、遮蔽运行或前向。
