## 定义

冻结作者HGEN提交ddd93c3的Generator/Discriminator/train逐字节不变，仅AST隔离顶层启动并加入不消耗随机数的日志回调。原整数节点抽样的梯度局限保留、如实报告，不加入straight-through或schema模型改造。

完整192节点和全部原边构成唯一训练参考。IMDB188/2/2分量完整保留，不沿用默认LCC裁剪；不做40%边留出。每个参考图的Hin2Vec按HGEN脚本链接的e-yi实现及固定32维/4epoch配方拟合一次，四GAN seed共享此固定资产，不能称四次完全独立的embedding流程。Hin2Vec节点重编号映射逐项保存，不用全图embedding截片或类型原型噪声。

HGEN原生从零target_g组装，提供参考总边数预算；它有这项显式条件，Diffusion无硬边数配额。保留原低支持直接返回和<=目标导致的过冲，不补边截边，不把边数接近自动归功于学习。

已知上游零支持事件没有可靠的原定义，因此单独命名“官方核心＋完整参考适配＋整条零支持提案拒绝兼容”。复用10月16日已验收函数，不均匀补节点、不加硬schema过滤。小夹具核验其正支持定义域与作者输出/RNG一致；每图20m提案/600秒看门狗，失败/部分图保留，不重抽。不能称原论文留出表格原样复现。

## 科学工作量与工程门

固定每fit24000完整图路径、5epoch、batch32，即3750D/750G；RMSprop1e-4、原clip、tau3和5层128维保持。训练后保存96000条节点/类型序列、score与pattern，再使用固定两个组装seed输出两图。无EMA、扩散链或后处理修图。

四训练seed清单与配方见protocol.json，源码/输入/资产绑定由source_manifest及各receipt给出。全部正式GAN从新状态开始，不继承工程更新。已完成8CPU接口测试，两参考各100次Hin2Vec/20D4G临时更新与256工程序列；无工程图进入科学样本。

成本按p95短测、八卡队列和1.5规划余量估算，不冒充已测八卡吞吐。原用户未指定精确墙钟，本实现主动采用09:11:12开始的90分钟内部保护窗口，10:26:12停止科学、10:41:12交付，不能写成用户明确批准的90分钟预算。只有输入/资产/CPU/数值/成本/八卡资源门全部通过才启动固定8fits；不足则报告，不缩图、缩epoch或减seed。
