## 数据流与改动

原E源码来自472e533fd28cfc067702b1b75082ac5105140a2d，旧结果/对照来自aa4227b9727ca6853ba7e26412ce6d438a0fa971。source_lineage.json记录实际文件核对；75份继承材料中，原package只改hsgd/model.py和vendor/conv_transformer_model.py，另增early_cn.py。数据、字典、ReFeX、RolX、normal2、损失、核、采样器、公共min/max和EMA没有修改。

1. 完整Xt产生原度/ReFeX/RolX节点残差。
2. 原CN支路用真实Xt边、原lin_in_E和共享首层形成节点上下文；它不读取新边残差，不递归执行主预测，不混入查询边。
3. 主计算图的真实边和查询边按无向对去重。每对计算一次原37维CN：32维学习均值、4维log1p类型计数、1维存在标记。
4. 新无偏置37→64线性投影，在主干lin_in_E之后、第一层Transformer之前相加一次。正反向行共享同一个投影；重复表示只映射，不重复累加。
5. 主干所有层照常运行。联合头移除末尾CN列，由776→128改为739→128，其余字段和两状态输出不变。

canonical_pairs只对元数据做CPU去重/回映射，计入完整前向耗时；没有N×N×N张量。CN学习表示不detach，仍沿原路径反传，资源上限未放宽。缓存属于单个FrozenTypedContext，原版本检查保留。未来分块仍需完整Xt，本票没有重写或证明块无关性。

## 工程结果

最终CPU10项通过、0失败、0跳过：无向去重/反向映射、空边/冲突、真实Xt支持、非零早期路径、原主干无残差行为、队列2训练/4链、旧结果匹配、缺项传播、模拟成功/失败监督、未授权正式入口拒绝。独立解包复验另记。

GPU使用获准空闲2080Ti的0/1卡，单进程线程1。每数据集3次临时normal2（连续1、2及恢复重做2），总6次，无超额。GPU已释放。
- 零投影与原E末端CN关闭对照：IMDB逐位一致；PubMed最大绝对logit差1.788e-7，原atol=2e-6/rtol=1e-5下0超差。不是与原E完整CN输出比较。
- 投影首步梯度范数：IMDB0.004262、PubMed0.02556；原CN编码器首步经此路径为0，第二步分别2.529e-5、1.979e-5。没有为通过修改初始化。
- 保存载入：模型、完整优化器、EMA、RNG精确一致；恢复后第二次更新的参数、优化器、EMA、梯度逐位一致，输入和离散状态一致。
- 非零投影下端点交换逐位一致；类型内重编号最大logit差IMDB1.192e-6、PubMed8.345e-7，均在原容差内。
- t=1/500/1000完整查询及原后验有限，IMDB13,120槽、PubMed18,336槽。未采样或提交下一图。
- EMA临时换入后原权重、模式、随机状态恢复。新增参数进入优化器和EMA。
- 实际attention dropout调用在原实现中注释掉；前向及一次真实训练更新未消耗Torch CPU/CUDA、Python、全局NumPy流，显式训练Generator按预期变化。这是本次实际路径检查，不声称任意将来随机模块仍有同样性质。

保留两类工程脚本失败：首次漏传assemble的state_version，更新前退出，累计0；CPU模拟进程缺wait方法，修正测试替身后通过。均不涉及科学模型变更。旧跨CPU/GPU失败没有改写，本票也未重测。
