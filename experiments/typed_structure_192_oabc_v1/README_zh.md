## 数学和接口

每类型节点两折固定不随状态变化。每个训练折以630列全部特征拟合：干净行乘sqrt(2)，六份噪声行不变；平方目标是四时间层各1/4加权目标的共同倍数。运行时始终使用未加权ReFeX。

每次验证仅以一侧315列做NNLS，再重建另一侧315列；交换方向。每方向先在留出节点及目标列求MSE，再取clean/4 + 六份noise各/8；最后平均两折两方向。评分标签列不进入当次系数求解。每类型K=1..min(8,两训练折节点数)，完整候选比较后最小误差，1e-12内同分取较小K。未收敛候选使整个选K关口失败，不能当作较差候选丢弃。

NMF：Frobenius、CD、NNDSVDa、tol1e-5、max_iter5000、无稀疏正则、shuffle=False、每候选一个固定初始化。单位L2基；非有限或零行失败。NNLS为FP64，max(240,30K)，原KKT门1e-7。系数强度保留，不做行概率归一化。全部随机流派生、节点折、列分组和实际Xt在evidence/dictionary_*中。

运行时C仅由当前完整Xt的ReFeX计算各类型系数，其他类型列为0，列偏移随K变化。字典为buffer，无CE反传。数据来源为同一训练小图及其原核加噪，是开发材料，不是独立拓扑泛化证据。
