## 二、准确性收益并非仅是“统一变稀”

原seed2026102812：raw平均边数640.5，EMA0.99为960.5；另一个原seed：1854.5降至986。存在向上与向下的调整，都接近926。跨训练seed的平均有符号边数偏差总体标准差由338.44降至41.54，这是描述性稳定性证据，不能代替上述绝对误差检验，也不证明整个生成分布已经准确。

不同seed始终是独立训练轨迹；同一seed的四种读出共享一条训练轨迹。两个样本及三种EMA不是额外独立训练重复。EMA带有平滑和时间滞后，不能从本实验唯一识别其作用机制。

## 四、结论和停止点

本面板支持：参数EMA能明显减轻一部分PubMed O训练seed的数量预测偏移，对新增seed也有多数改善；收益依赖seed和衰减尺度，并有连通、尾部或三角代价。它不是CN／RolX角色机制的贡献，也不是跨图、跨数据集有效性证明。

不能据此宣布所有生成不稳定已解决；也不因两个seed恶化而忽略其余改善。0.99保留为预定主比较，0.9／0.97是完整敏感性结果，不事后改成唯一获胜方案。本轮交付后停止，无新训练、采样、校准、修图或下一候选。
