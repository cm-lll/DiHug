## 唯一提交审查的损失

对完整无向可动槽集合J_r，K_r=|J_r|；p_i为原网络有边p0，m_r为本份训练目标X0关系边数。若有固定有边支持，记其数量b_r：

    mu_r = b_r + sum_{i in J_r} p_i
    U = {r : K_r > 0}, R = |U|
    L_count = (1/R) * sum_{r in U} (mu_r-m_r)^2 / (K_r * max(m_r,1))
    L_input = sumCE / 18336 + 0.01 * L_count
    L_normal2 = (L_input_1 + L_input_2) / 2

一次清梯度，两份独立Xt各自反向并释放计算图，最后一次AdamW与一次EMA更新。原CE尺度不变，辅助项不再次除以18336。FP32网络及原softmax/支持投影不变，p0转FP64求和可微；不是q。槽ID全覆盖/唯一性沿用原normal2检查，不能把有向存储的反向边重复求和。

归一化相当于平方密度误差除以目标密度（目标0用一条边/K作为下限），抑制大候选集合上的纯相对误差爆炸；它不是所有关系相同相对误差等权。关系普通均值分母为有可动槽的关系数，当前IMDB为5，PubMed为10。无可动槽关系不参与平均，但目标必须与固定支持一致；全无可动槽时返回可微0。零目标且有可动槽时分母为K。零目标不等于禁止关系，实际可动支持由原冻结prior决定。

lambda固定0.01，两数据集/全部关系共用；没有依生成效果调参。它是有监督辅助目标，改变原CE目标，不是无损优化、边数配额或推理概率控制。目标边数只进入训练损失/评价，不进入模型输入。全图分块下不能把各块平方误差平均冒充上述完整和的平方，完整图需另行设计和授权。
